# 评测说明

此项目提供三个自动创建的临时 Git 仓库任务：字符串 slug 空白处理、零分母处理、Fibonacci 基准值。它们是验证工具链的小样例，不能代表大型仓库任务难度。

判定由 Harness 外部独立进行：初始测试必须失败；Agent 执行后测试必须退出 0；原测试文件必须保持不变；Git diff 必须仅包含 module.py；执行异常导致失败。目标判断状态单独记录，模型声称完成不决定外部测试结果。

`--mode demo` 使用预定义工具序列，测试可重复性。`--mode live` 调用 `.env` 中的模型；`--case slug-spaces` 等选项便于复跑一个案例。报告保存在 `.repopilot/`，不提交包含完整交互的原始报告。依赖网络的连接失败应单独报告，不据此推断代码生成能力。

2026-09-18 本地验证：38 项自动测试通过，固定脚本三个样例通过。真实模型 slug-spaces 样例首次完成；zero-division 与 fibonacci-zero 首次遇到连接错误，重试后分别完成。三个最终结果均经过外部测试重跑与修改范围检查。这里保留网络失败记录，不把重试后的三个成功结果当作首次尝试完成率或大型仓库基准，也不据此宣称生产可靠性或相对基础 Agent 的提升。

后续可以固定模型版本和运行配置，添加真实仓库 bug、跨文件重构与失败诊断任务；对基础循环、上下文管理和完整 Harness 分组做消融比较，统计完成率、耗时、模型调用成本、修改范围违规及判断误报。
